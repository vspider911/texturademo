# Texturademo — демо-сайт барбершопа «Текстура»

Демо-версия сайта барбершопа «Текстура» (Москва, ул. Генерала Белова, 1/8).

Реальные: название, адрес и как добраться, часы работы, отзывы и имена мастеров из отзывов на Яндекс Картах, акция «−300 ₽ по промокоду ПЕРВЫЙ», карта и кнопка «Маршрут».
Условные: телефон `+7 (000) 000-00-00`, цены, рейтинг, ссылки на мессенджеры.
Сверху полоса «Демо-версия сайта — телефон, цены и рейтинг условные».

## Что на сайте
- Первый экран с рейтингом, часами работы и статусом «Открыто / Закрыто» по московскому времени.
- Прайс с переключателем «Барбер / Старший барбер / Эксперт»: одна услуга — одна цена для выбранного уровня.
- Акция −300 ₽ на первую стрижку: промокод применяется прямо в форме записи.
- Липкая сцена «Как проходит визит».
- Мастера, которых хвалят в отзывах.
- Онлайн-запись: уровень мастера, услуги с подсчётом суммы, день и время (занятые слоты зачёркнуты), имя, телефон, промокод. Заявка никуда не отправляется.
- Атмосфера, отзывы, контакты, Яндекс Карта.
- На телефоне внизу закреплены кнопки «Позвонить» и «Записаться».

Фото — бесплатные снимки с Unsplash в формате WebP, лежат в `img/`.

## Как открыть
Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python -m http.server 8000
```

и перейдите на http://localhost:8000
